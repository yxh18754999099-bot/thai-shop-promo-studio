# Thai Shop Promo Studio 🧟 (Kiroween 2026 · Frankenstein)

A stitched-together promo-video tool for small Thai TikTok Shop clothing sellers:

1. **Video** – generate a short product clip from a photo + prompt (Wan2.2 TI2V-5B).
2. **Voice** – Thai female text-to-speech voiceover.
3. **Captions** – auto-timed, TikTok-style Thai pop-up subtitles burned into the video.

Built with Kiro: specs in `.kiro/specs`, steering in `.kiro/steering`, agent hooks in `.kiro/hooks`.

## Status
Work in progress for Kiroween 2026 (Oct 30 – Dec 4, 2026).
